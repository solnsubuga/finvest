# @finvest/market

The Bank of Uganda's most recent Treasury bill and bond auction results, kept by hand in `src/index.ts`.

- The website's products page shows the after-tax (`net…`) fields.
- The console's Rates screen shows the bill auction, before tax, as its Last auction tile, so staff can set Finvest's rates against it.

Update the file after each auction, from the results the Bank of Uganda publishes at bou.or.ug. Every after-tax figure has its working in a comment beside it.
